# Parameter values for the MEMC model configuration

Parameter values for the MEMC model configuration

## Usage

``` r
data(memc_params)
```

## Format

A data frame of 20 rows and 4 columns containing the default MEMC
parameter values

- parameter:

  String indicating MEMC parameter.

- description:

  String describing the parameter.

- units:

  String of the parameter units.

- value:

  Parameter values

## References

Wang et al.: Development of microbial-enzyme-mediated decomposition
model parameters through steady-state and dynamic analyses, Ecol. Appl.,
23, 255–272, 2013. <https://doi.org/10.1890/12-0681.1>

## See also

Other inputs:
[`memc_initial_state`](https://microbial-explicit-model.github.io/MEMC/reference/memc_initial_state.md)
